# MVP Scope

Included:

- Register/login.
- Create circles.
- Invite or simulate members.
- Assign owner, approver, contributor, and viewer roles.
- Upload local images.
- Generate thumbnail and display copies.
- Submit, approve, reject, or request changes for memories.
- Generate simple album pages from approved memories.
- Display album pages in a responsive Flutter flip view.
- Seed demo data.

Excluded:

- Live Google Drive, iCloud, and OneDrive connectors.
- Peer-to-peer sync and restore.
- AI clustering.
- Advanced graphics editing.
- Subscriptions and public sharing.
