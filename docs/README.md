# Memory Circle Docs

Memory Circle is a collaborative digital memory album. The MVP includes account creation, circles, member roles, image upload with thumbnail/display copies, memory submission, approval, generated album pages, and a responsive flip-album client.

Start with `ARCHITECTURE.md`, then use `API.md` and `TESTING.md` while developing.

For Codex, Claude, and human co-management, use `CO_MANAGEMENT.md` and leave
short baton passes in `HANDOFF.md`.

Use `ALBUM_PHOTO_COUNT_PLAN.md` to approve the default album photo-count rule.

Use `PUSH_NOTIFICATIONS.md` to configure Firebase Cloud Messaging.
